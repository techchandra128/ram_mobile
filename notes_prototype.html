Tablet Format
Memory & Encoding
What is Memory

• Memory is the process of encoding, storing and retrieving information.

Encoding converts experience into neural patterns.

Without encoding there is no memory formation.

• Three stages: encoding → storage → retrieval.

Each stage can be a point of failure or strength.

Sensory Memory

• Lasts less than 1 second for visual input (iconic).

Auditory sensory memory lasts about 3–4 seconds (echoic).

• Acts as a filter — only attended items pass to STM.

This is controlled by selective attention.

Unattended information decays almost immediately.

Short-Term Memory

• Capacity limited to ~7 ± 2 items (Miller's Law).

Chunking can expand effective capacity.

• Duration approximately 15–30 seconds without rehearsal.

Maintenance rehearsal keeps items alive in STM.

Elaborative rehearsal moves items to LTM.

Note: the distinction between STM and working memory is debated — Baddeley's model treats working memory as a more active and structured system.
// Encoding types semantic → meaning-based (deepest, most durable) acoustic → sound-based visual → image-based (shallowest)
