## Shipped

### PWA Mobile App — Installable on Phones
- **What it is:** Full mobile version of RAM — installable on Android/iOS, works offline
- **When shipped:** Before 2026-06-05
- **Live at:** `myramyoga.uk/mobile.html`
- **Key parts:** Library, Dashboard, Diary, Smart Desk, Cornell notes, Series modal

### Web App — Live Online
- **What it is:** Desktop version of RAM deployed to GitHub Pages
- **When shipped:** 2026-06-05
- **Live at:** `myramyoga.uk`
- **Key parts:** Full 5-column file view, sidebar with Lucide icons, all sections, playlists, campaigns, diary, smart desk, dashboard

### Revision System (Spaced Repetition)
- **What it is:** Column 5 in file view — tracks how well you know each section, schedules revision using Fibonacci spacing
- **When shipped:** Before 2026-06-05

### Supabase Connection
- **What it is:** Cloud database connected — data syncs to/from Supabase
- **When shipped:** Before 2026-06-05

### All Sections Batch Rendering
- **What it is:** Instead of loading all sections at once (slow), loads 100 at a time with "Load more" button
- **When shipped:** 2026-06-05

### Lucide SVG Sidebar Icons
- **What it is:** Replaced emoji icons in sidebar with clean professional SVG icons from Lucide library, stored locally
- **When shipped:** 2026-06-05
